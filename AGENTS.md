## Project Overview

- This project is an Astro-based personal homepage.
- The final deployment target is a GitHub Pages `github.io` address.

## Rules for AI Agents

1. Do not add new libraries without the user's approval.
2. Do not modify unrelated files.
3. Do not write secrets, tokens, passwords, or API keys in code.
4. Always ask before running delete commands.
5. After making changes, explain which files were changed and why.
6. When possible, verify changes with `npm run build`.
7. Commit changes frequently when there are modifications.
8. Use commit messages in one of the following formats:
   - `feat: 한국어설명`
   - `fix: 한국어설명`
   - `chore: 한국어설명`
   - `docs: 한국어설명`
9. When presenting a command, explain what the command does in a way that beginners can understand.
10. Clearly state whether the command is safe to run.
